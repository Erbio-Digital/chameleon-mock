# Zendesk

Simulates the Zendesk Support API surface listed below for local tests. Not affiliated with Zendesk.

## Covered

- Tickets: create, read, update, comments.
- Search and attachments.
- Webhooks: ticket status changes, signed.
- Agent e-mail and API token authentication.

## Sources

- https://developer.zendesk.com/api-reference/ticketing/tickets/tickets/
- https://developer.zendesk.com/documentation/webhooks/
